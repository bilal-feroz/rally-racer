# Timberline Rally

This folder holds the game itself. The full readme, with controls, screenshots and itch.io notes, is at the [root of the repository](../README.md).

Quick start:

```bash
npm install
npm run dev
```

Then open http://127.0.0.1:5173.

Other useful commands:

- `npm run build` makes a production build in `dist`
- `npm run preview` serves that build at http://127.0.0.1:4173
- `npm test` runs the Playwright tests

Notes from development live in `docs`, and the helper scripts used for screenshots, the demo video and the handling tests live in `scripts`.
